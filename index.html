NZ Growing-Season Climate & Kiwifruit Yield

Aug 2026
StackPython, pandas, pdfplumber, scipy, matplotlib, pytest
TypeIndependent project
ScopeTen districts, six seasons, 38 features

Does growing-season weather track kiwifruit yield? Getting to an answer meant building the dataset first: five sources, including annual report PDFs whose table layouts change between editions, and reconciling two publishers against each other. That reconciliation surfaced a defect in an official published source, where three seasons of yield figures had been printed in the hectares row. The check that catches it is a validation rule, so a repeat is caught without a code change.

Every feature's variance is split between seasons, districts and residual before anything is fitted, and that table decides what may be asked. Winter chill is absent from the results because 69 to 83 percent of its variance sits between districts, so it cannot be separated from everything else that differs between districts. The code refuses to test it rather than printing a number someone would read as an association.

One association holds: wetter fruit-fill periods go with lower yield, r of -0.91 and -0.95, still substantial after dropping the most influential season. It does not survive correction for the 38 features tested, and the write-up says so. A pre-committed hypothesis came out backwards, and that is reported too. 122 tests, and the pipeline runs top to bottom from a clean checkout.

Ticket Analytics Pipeline & Natural-Language SQL Agent

Jul 2026
StackPython, pandas, DuckDB, SQL, Power BI, Streamlit
TypeIndependent project
Data100,000 rows, deliberately dirty

An unfamiliar operational dataset with quality problems built into it, taken from raw file to trustworthy reporting layer. The cleaning runs across five notebooks: profiling, validation rules, category standardisation mapping 32 inconsistent values down to 10, and quality flags rather than silent deletions, with every decision written down so someone else can disagree with it.

The cleaned output is modelled into a star schema and written to parquet, then surfaced through Power BI where every headline figure was independently recomputed in pandas before being trusted. On top sits an agent that answers plain-English questions by generating and executing real SQL against DuckDB, behind a SELECT-only guard that was tested by firing destructive statements at it before the model was ever connected.

Market Signal & Paper-Trading Tool

2026
StackPython, pandas, Streamlit, Binance public API, VADER
TypeIndependent project
CodePublic repository

A signal engine and autonomous paper-trading bot, from live market data through to simulated execution on a testnet. Indicators are computed from scratch rather than pulled from a library: MACD, RSI, Bollinger Bands, moving averages, and a 200-period trend regime, combined into a transparent verdict that states its own reasons. News headlines are scored for sentiment as a secondary input.

The interesting half is the validation. The strategy is put through a train and test split, walk-forward validation, cross-asset robustness testing, and a survivorship-bias check against a coin that collapsed. The honest conclusion the project reaches is that disciplined risk management holds up and prediction does not, which is the opposite of what a project like this usually claims.
